## 🚀 Getting Started

Each project is self-contained in its own folder. To run a project:

- **C# projects** — open the `.sln` in Visual Studio and hit Run.
- **JavaScript / HTML projects** — open `index.html` in a browser, or use a local dev server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer).
- **Java projects** — open in IntelliJ IDEA or compile with `javac`.
- **PHP projects** — serve with a local PHP server: `php -S localhost:8000`.
